# GTNH Pattern Checker（AE2 样板检查器）

为 **Minecraft 1.7.10 / GTNH** 开发的 AE2 样板检查工具

> **AI 构建声明**：本仓库的全部代码由 AI 模型（WorkBuddy / GLM 智能体）生成，无任何人类手写代码，连 github 都是 AI 上传，纯石山。

> 设计参考：[3QQQ/PatternChecker](https://github.com/3QQQ/PatternChecker)（NeoForge 1.21.1 版样板检查器，功能设计来源）。
> AE2 样板 NBT 格式与 NEI 分发链经字节码级反汇编分析后针对 1.7.10 独立实现，未复制原项目源码。
> 详见下方「许可」。

## 特性

- **样板全量扫描**：扫描 ME 网络**接口样板槽 + ME 存储**中的所有样板，检出无法解析、配方失效、数量异常（≤0）、自循环、输入无法由网络供给、未注册合成缓存、重复样板等问题。
- **图形化面板**：手持工具右键空气打开；问题列表选中后可**高亮**（世界线框）、**编辑**、**取出**、**忽略**。
- **忽略功能**：按样板内容指纹忽略已审阅的样板，不计入错误/警告、不出现在列表；「显示已忽略」可随时找回并取消；按玩家持久化到服务器 `config/gtnhpatternchecker-ignored.txt`。
- **3×3 九宫格编辑器**：幽灵槽逐格编辑处理样板数量；支持 NEI 物品面板拖入、按 R 后合成表一键填入；÷10 ÷2 −1 +1 ×2 ×10 按钮批量调整；编码后直接写回接口样板槽并保留原样板附加 NBT（`tunnelUuid`、第三方字段等）。
- **第三方兼容**：AE2FC 二合一接口（线缆部件形态）可正常取出/编辑；`wildcardpattern` 通配样板识别为第三方样板，不误报。

## 版本历史

### v0.5.1（当前）
- 编辑器槽位数量改到物品**右下角**、缩小到 0.7 倍，并绘制在贴图之上（原先会被图标压住）
- 修复 AE2FC 液滴显示为「???液滴」：物品名描述符现在附带小体积 NBT，客户端能还原液滴对应的流体
- **合成样板恢复可编辑**：3×3 九宫格与合成样板布局一致，上传时保留 `crafting` 标记与单输出结构（此前只有处理样板能编辑）

### v0.5.0
- 面板物品名改由客户端翻译（专用服务器没有语言文件，之前会把 `Encoded Pattern` 这类英文名发给玩家）

- 3×3 九宫格编辑器：玩家背包可点击、数量按钮立即生效、幽灵槽 tooltip

- 新增忽略 / 取消忽略 / 显示已忽略
- 线程安全（Netty 包处理调度回主线程）与会话存储清理
