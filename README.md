# GTNH Pattern Checker（AE2 样板检查器）

为 **Minecraft 1.7.10 / GTNH** 开发的 AE2 样板检查工具

> **AI 构建声明**：本仓库的全部代码由 AI 模型（WorkBuddy / GLM 智能体）生成，无任何人类手写代码，连 github 都是 AI 上传，纯石山。

> 设计参考：[3QQQ/PatternChecker](https://github.com/3QQQ/PatternChecker)（NeoForge 1.21.1 版样板检查器，功能设计来源）。
> AE2 样板 NBT 格式与 NEI 分发链经字节码级反汇编分析后针对 1.7.10 独立实现，未复制原项目源码。
> 详见下方「许可」。

## 特性

- **全量扫描**：一键扫描 ME 网络接口样板槽 + ME 存储，`/patterncheck scan all` 覆盖所有已加载维度
- **问题检测**：无法解析、配方失效、数量异常（≤0）、自循环、输入无法供给、未注册合成缓存、重复样板
- **图形面板**：问题列表按严重度排序，支持高亮定位、编辑、取出、忽略；鼠标拖动滚动条；最多 2000 行，分页传输不受单包 32KB 限制
- **忽略功能**：按内容指纹忽略样板；「显示已忽略」随时找回（含已被取出/移除样板的占位行），按玩家持久化
- **健康样板**：默认隐藏，一键切换显示，可直接选中编辑
- **3×3 编辑器**：逐格编辑数量，NEI 拖入 / R 键合成表填入，批量倍率按钮，编码后写回接口并保留原 NBT
- **第三方兼容**：AE2FC 二合一接口、wildcardpattern 通配样板（识别不误报）；物品名客户端本地化（含流体）
- **NEI 快捷键**：编辑器幽灵槽内 R 查配方、U 查用途、A 收藏书签（跟随 NEI 键位配置），配方可直接填充到网格
